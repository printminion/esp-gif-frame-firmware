# esp-gif-frame firmware

Web installer and firmware distribution for **esp-gif-frame** — a GIF animation player for Seeed Studio XIAO ESP32 devices with a 1.28" touch display.

## Install firmware

Open the web installer and follow the on-screen steps:

**<https://printminion.github.io/esp-gif-frame-firmware/>**

Requires Google Chrome or Microsoft Edge (WebSerial support). Connect your device via USB before clicking Install.

## Supported devices

| Device | Chip family |
| ------ | ----------- |
| Seeed Studio XIAO ESP32-C3 + seeed_touch | XIAO ESP32-C3 |
| Seeed Studio XIAO ESP32-S3 + seeed_touch | XIAO ESP32-S3 |

## Firmware channels

- **release** — stable builds
- **development** — latest builds from upstream CI
